HARE — Module

HARE - Heteroskedasticity and Autocorrelation Estimators

Classical feasible GLS correction methods for linear regression models, including multiplicative heteroskedasticity (Harvey 1976), AR(1) serial correlation (Prais-Winsten, Hildreth-Lu, Cochrane-Orcutt), and joint correction via the Sequential HARE estimator (Oberhofer-Kmenta 1974) and the Beach-MacKinnon (1978) exact MLE.

HARE.HAREModel — Type
HAREModel

Abstract supertype for all HARE estimator result objects. Subtypes support the StatsBase interface: coef, stderror, vcov, residuals, fitted, and predict.

HARE.FWLSResult — Type
FWLSResult <: HAREModel

Result of a Feasible Weighted Least Squares (FWLS) estimator for heteroskedastic regression. Returned by exponential_fwls, exponential_ifwls, quadratic_fwls, quadratic_ifwls, linear_fwls, and linear_ifwls.

Fields

  • coefnames : coefficient names.
  • mf : ModelFrame from formula fit; nothing for matrix fit.
  • vcov : estimated covariance matrix of beta_hat.
  • residuals : residuals in the original space, y - X*beta_hat.
  • fitted : fitted values X*beta_hat.
  • gamma : estimated variance-equation coefficients gamma_hat.
  • gamma_vcov : estimated covariance matrix of gamma_hat (from the auxiliary OLS regression).
  • iterations : number of FWLS iterations performed.
  • converged : true if the convergence criterion was satisfied.
  • link : variance model — :exponential, :quadratic, or :linear.

Heteroskedasticity FWLS Estimators

HARE.exponential_fwls — Function
exponential_fwls(X, y; Z=nothing, intercept=true) -> FWLSResult
exponential_fwls(formula, data; Z=nothing) -> FWLSResult

Two-step Feasible Weighted Least Squares for multiplicative heteroskedasticity (Harvey 1976). Models the log-variance as a linear function of auxiliary regressors:

\[\begin{aligned} \sigma_i^2 &= \exp(\gamma_0 + \mathbf{z}_i^\top\boldsymbol{\gamma}) \end{aligned}\]

Step 1. OLS → residuals û. Step 2. Auxiliary regression log(û²ᵢ) - c = Zᵢγ + vᵢ → weights wᵢ = 1/exp(Zᵢγ̂). Step 3. WLS with weights w.

Arguments

  • X : n × k regressor matrix without a constant column.
  • y : response vector of length n.
  • intercept: if true (default), a constant column is prepended to X.
  • formula : @formula expression (formula method).
  • data : Tables.jl-compatible data source (formula method).
  • Z : auxiliary regressor matrix for the variance equation, without a constant column (default: X). A constant is prepended internally.

Returns

FWLSResult.

References

Harvey, A. C. (1976). Estimating regression models with multiplicative heteroscedasticity. Econometrica, 44(3), 461–465.

HARE.power_fwls — Function
power_fwls(X, y; Z, intercept=true) -> FWLSResult
power_fwls(formula, data; Z) -> FWLSResult

Two-step FWLS for heteroskedasticity with a power variance function. The variance is modelled as:

\[\sigma_i^2 = \sigma^2 \prod_j |z_{ij}|^{2\delta_j}\]

Equivalently, $\log\sigma_i^2 = \log\sigma^2 + 2\delta_1\log|z_{i1}| + \cdots$, which is the exponential (Harvey) model on $\log|Z|$. The reported $\boldsymbol{\gamma} = (\gamma_0, \gamma_1, \ldots)$ satisfies $\gamma_0 = \log\sigma^2$ and $\gamma_j = 2\delta_j$. Standard errors are exact — no delta-method approximation.

Arguments

  • X : n × k regressor matrix without a constant column.
  • y : response vector of length n.
  • intercept: if true (default), a constant column is prepended to X.
  • formula : @formula expression (formula method).
  • data : Tables.jl-compatible data source (formula method).
  • Z : auxiliary regressor matrix without a constant column. A constant is prepended internally. Required for the power model.

Returns

FWLSResult with link = :power.

HARE.exponential_mle — Function
exponential_mle(X, y; Z=nothing, intercept=true, tol=1e-10, maxiter=1000) -> MLEResult
exponential_mle(formula, data; Z=nothing, tol=1e-10, maxiter=1000) -> MLEResult

Maximum likelihood estimation of the heteroskedastic regression model with an exponential variance function (Harvey 1976):

\[\begin{aligned} y_i &= \mathbf{x}_i^\top\boldsymbol{\beta} + \varepsilon_i, \qquad \varepsilon_i \sim \mathcal{N}(0,\,\sigma_i^2) \\[4pt] \sigma_i^2 &= \exp(\gamma_0 + \mathbf{z}_i^\top\boldsymbol{\gamma}) \end{aligned}\]

The log-likelihood is maximised jointly over $(\boldsymbol{\beta}, \boldsymbol{\gamma})$ using L-BFGS with automatic differentiation. Two-step Harvey FWLS estimates serve as warm starts. Standard errors come from the inverse observed information matrix.

Corresponds to SAS PROC AUTOREG HETERO LINK=EXP.

Arguments

  • X : n × k regressor matrix without a constant column.
  • y : response vector of length n.
  • intercept: if true (default), a constant column is prepended to X.
  • Z : n × p auxiliary regressor matrix for the variance equation, without a constant column (default: X). A constant is prepended internally.
  • formula : @formula expression (formula method).
  • data : Tables.jl-compatible data source (formula method).
  • tol : gradient norm tolerance for L-BFGS convergence, per observation (default 1e-10).
  • maxiter : maximum number of L-BFGS iterations (default 1000).

Returns

MLEResult with link = :exponential.

References

Harvey, A. C. (1976). Estimating regression models with multiplicative heteroscedasticity. Econometrica, 44(3), 461–465.

Groupwise Heteroscedasticity

HARE.two_step_groupwise — Function
two_step_groupwise(X, y, groups; intercept=true) -> GroupwiseResult
two_step_groupwise(formula, data, groups) -> GroupwiseResult

Two-step Feasible GLS for groupwise heteroskedasticity (Greene §9.7.2).

Step 1. OLS → estimate σ̂²g = (1/ng) Σ{i∈g} ûi² for each group g. Step 2. WLS with weights wi = 1/σ̂²g.

Standard errors are conditional on σ̂²_g (WLS sandwich).

Arguments

  • X : n × k regressor matrix without a constant column.
  • y : response vector of length n.
  • groups : length-n vector of group labels (any type: integers, strings, …).
  • intercept: if true (default), a constant column is prepended to X.
  • formula : @formula expression (formula method).
  • data : Tables.jl-compatible data source (formula method).

Returns

GroupwiseResult.

References

Greene, W. H. (2018). Econometric Analysis (8th ed.). Pearson, §9.7.2.

HARE.iterated_groupwise — Function
iterated_groupwise(X, y, groups; intercept=true, tol=1e-8, maxiter=100) -> GroupwiseResult
iterated_groupwise(formula, data, groups; tol=1e-8, maxiter=100) -> GroupwiseResult

Iterated Feasible GLS for groupwise heteroskedasticity (Greene §9.7.2).

Each iteration:

  1. Update σ̂²g = (1/ng) Σ{i∈g} ûi² from current residuals.
  2. Update β by WLS with weights wi = 1/σ̂²g.

Convergence criterion: max|β(i) − β(i−1)| < tol.

At convergence this is equivalent to the joint MLE of (β, σ²1, …, σ²G), since the MLE first-order conditions for σ²_g reduce to the within-group sample variance.

Arguments

  • X : n × k regressor matrix without a constant column.
  • y : response vector of length n.
  • groups : length-n vector of group labels.
  • intercept: if true (default), a constant column is prepended to X.
  • formula : @formula expression (formula method).
  • data : Tables.jl-compatible data source (formula method).
  • tol : convergence tolerance (default 1e-8).
  • maxiter : maximum number of iterations (default 100).

Returns

GroupwiseResult.

References

Greene, W. H. (2018). Econometric Analysis (8th ed.). Pearson, §9.7.2.

HARE.groupwise_mle — Function
groupwise_mle(X, y, groups; intercept=true, tol=1e-8, maxiter=100) -> GroupwiseResult
groupwise_mle(formula, data, groups; tol=1e-8, maxiter=100) -> GroupwiseResult

Maximum likelihood estimation for groupwise heteroskedasticity.

The model is:

\[y_i = \mathbf{x}_i^\top\boldsymbol{\beta} + \varepsilon_i, \qquad \varepsilon_i \sim \mathcal{N}(0,\,\sigma_g^2), \quad i \in g\]

The MLE first-order conditions are:

  • $\hat{\boldsymbol{\beta}}$: WLS with weights $1/\sigma_g^2$
  • $\hat{\sigma}_g^2 = \frac{1}{n_g}\sum_{i \in g}\hat{u}_i^2$

These are solved by coordinate descent (alternating WLS and variance updates) until $\max|\hat{\boldsymbol{\beta}}^{(t)} - \hat{\boldsymbol{\beta}}^{(t-1)}| < \texttt{tol}$.

Standard errors come from the exact observed information matrix $(\mathbf{X}^\top\mathbf{W}\mathbf{X})^{-1}$, not from GLM's dispersion-scaled covariance. This is the key difference from iterated_groupwise, which gives identical point estimates but slightly different standard errors in finite samples.

Arguments

  • X : n × k regressor matrix without a constant column.
  • y : response vector of length n.
  • groups : length-n vector of group labels (any type: integers, strings, …).
  • intercept: if true (default), a constant column is prepended to X.
  • formula : @formula expression (formula method).
  • data : Tables.jl-compatible data source (formula method).
  • tol : convergence tolerance (default 1e-8).
  • maxiter : maximum number of iterations (default 100).

Returns

GroupwiseResult.

References

Greene, W. H. (2018). Econometric Analysis (8th ed.). Pearson, §9.7.2.

two_step_prais_winsten(X, y; intercept=true) -> AR1Result

Two-step Prais-Winsten GLS estimator correcting for AR(1) autocorrelation.

HARE.harvey_test — Function
harvey_test(X, y; intercept=true, Z=nothing) -> HarveyTestResult
harvey_test(formula, data; Z=nothing) -> HarveyTestResult

Lagrange multiplier test for multiplicative heteroskedasticity (Harvey 1976).

Tests H₀: γ = 0 in the exponential variance model log(σᵢ²) = γ₀ + zᵢ'γ.

The test statistic is

LM = ESS / trigamma(1/2)

where ESS is the explained sum of squares from the auxiliary OLS regression of log(ûᵢ²) − c on Z (c = E[log(χ²(1))] = −1.2703628454614782), and trigamma(1/2) = π²/2 is the variance of log(χ²(1)). The statistic is distributed as χ²(p) under H₀, where p = dim(γ) (columns of Z excluding the intercept).

This is Harvey's (1976) exact score-test formula. It differs from the generic LM form n·R² but is asymptotically equivalent.

  • X : n × k regressor matrix without a constant column.
  • y : response vector of length n.
  • intercept: if true (default), a constant is prepended to X.
  • formula : @formula expression (formula method).
  • data : Tables.jl-compatible data source (formula method).
  • Z : auxiliary regressor matrix for the variance equation, without a constant column (default: X). A constant is prepended internally.

HARE.glejser_test — Function
glejser_test(X, y; intercept=true, Z=nothing) -> GlejserTestResult
glejser_test(formula, data; Z=nothing) -> GlejserTestResult

Lagrange multiplier test for heteroskedasticity with a linear standard deviation (Glejser 1969).

Tests H₀: γ = 0 in the quadratic variance model σᵢ = γ₀ + zᵢ'γ.

The test statistic is

LM = ESS_|û| / (σ̂² · (1 − 2/π))

where ESS_|û| is the explained sum of squares from the auxiliary OLS regression of |ûᵢ| on Z, σ̂² = (1/n)Σûᵢ² is the OLS variance estimate from the main regression, and (1 − 2/π) = Var(|N(0,1)|) is the variance of the half-normal. The statistic is distributed as χ²(p) under H₀, where p = dim(γ) (columns of Z excluding the intercept).

This is Glejser's (1969) exact score-test formula. It differs from the generic LM form n·R² but is asymptotically equivalent.

Durbin-Watson test for first-order serial correlation in OLS residuals.
