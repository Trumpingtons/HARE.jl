HARE.jl – Tutorial

This tutorial demonstrates estimators in HARE.jl using the formula interface. Every function also accepts a matrix interface f(X, y; ...) where X is the regressor matrix without a constant column; both signatures are shown for the first estimator and listed for all estimators in the API Reference. Each section simulates data appropriate for that estimator.

Setup

\[\begin{aligned} y_i &= \mathbf{x}_i^\top \boldsymbol{\beta} + \varepsilon_i, \qquad \varepsilon_i \sim \mathcal{N}(0,\,\sigma_i^2) \end{aligned}\]

For this tutorial, as exogenous variables we generate two sets of random samples ($\mathbf{x}_{1}$) and ($\mathbf{x}_{2}$), normally distributed. The response variable ($y$) is given by

\[\begin{aligned} y_i &= \beta_0+\beta_{1}\, \mathbf{x}_{1i} + \beta_{2}\, \mathbf{x}_{2i} + \varepsilon_i \end{aligned}\]

using HARE
using Random, LinearAlgebra, GLM, StatsBase

Random.seed!(1234)

nobs   = 500
x1     = randn(nobs)
x2     = randn(nobs)
b = [1.0, 2.0, -1.0];              # beta true parameters

Exponential Variance Model:

The Harvey (1976) model specifies multiplicative heteroskedasticity via an exponential variance function:

\[\begin{aligned} \sigma_i^2 &= \sigma^2_0 \exp(\mathbf{z}_i^\top \boldsymbol{\gamma}) \end{aligned}\]

We simulate data with log variance proportional to $|\mathbf{x}_1|$ and $\sigma_0=1$.

sigma_0 = 1.0;
gamma   = [1.0, 0.0];
sigma_exp = sigma_0 * exp.((gamma[1] .* abs.(x1) .+ gamma[2] .* x2) ./ 2);

The simulated dataset ($data$) is

y    = b[1] .+ b[2] .* x1 .+ b[3] .* x2 .+ sigma_exp .* randn(nobs);
data = (y = y, x1 = x1, x2 = x2);

MLE (exponential_mle): jointly maximises the log-likelihood over $(\boldsymbol{\beta}, \boldsymbol{\gamma})$ via L-BFGS, warm-started from the Harvey auxiliary regression. Equivalent to R's nlme::gls(weights = varComb(varExp(...))).

Power Variance Model

The power variance model (Harvey 1976, multiplicative form) specifies:

\[\begin{aligned} \sigma_i^2 &= \sigma^2 \prod_j |z_{ij}|^{2\delta_j} \end{aligned}\]

Equivalently, $\log\sigma_i^2 = \log\sigma^2 + 2\delta_1\log|z_{i1}| + \cdots$, which is the Harvey exponential model applied to $\log|Z|$. The reported $\boldsymbol{\gamma} = (\sigma^2, \delta_1, \ldots)$ is obtained via the delta-method reparametrisation.

We simulate data with $\sigma_i^2 = |x_1|$ (i.e.\ $\sigma^2 = 1$, $\delta_1 = 0.5$).

sigma_pow = abs.(x1) .^ 0.5;
y_pow     = b[1] .+ b[2] .* x1 .+ b[3] .* x2 .+ sigma_pow .* randn(nobs);
data_pow  = (y = y_pow, x1 = x1, x2 = x2);

MLE (power_mle): joint MLE warm-started from the Harvey auxiliary regression on $\log|Z|$. Reports $(\sigma^2, \delta_1, \ldots)$ with delta-method standard errors.

power_mle(@formula(y ~ x1 + x2), data_pow; Z = @formula(0 ~ abs(x1)))

Quadratic Variance Model

The Glejser (1969) model assumes the standard deviation is linear in auxiliary regressors $\mathbf{z}_i$:

\[\begin{aligned} \sigma_i &= \sigma_0 + \mathbf{z}_i^\top \boldsymbol{\gamma} \end{aligned}\]

We simulate data with $\sigma_i$ linear in $|\mathbf{x}_1|$.

Because the variance depends on $|\mathbf{x}_1|$, not $\mathbf{x}_1$ itself, we supply a custom auxiliary regressor matrix Z = [|x1|, x2] so the Glejser auxiliary regression is correctly specified. Using the raw regressors would yield a badly biased gamma.

sigma = 0.5 .+ 0.3 .* abs.(x1);
y = b[1] .+ b[2] .* x1 .+ b[3] .* x2 .+ sigma .* randn(nobs);
data = (y = y, x1 = x1, x2 = x2);
quadratic_mle(@formula(y ~ x1 + x2), data; Z = @formula(0 ~ abs(x1) + x2))

Linear Variance Model

The linear variance model specifies the variance as a linear combination of auxiliary regressors $\mathbf{z}_i$:

\[\begin{aligned} \sigma_i^2 &= \gamma_0 + \mathbf{z}_i^\top \boldsymbol{\gamma} \end{aligned}\]

We simulate data with $\sigma_i^2$ linear in $|\mathbf{x}_1|$.

sigma2 = 0.5 .+ 0.3 .* abs.(x1);
y = b[1] .+ b[2] .* x1 .+ b[3] .* x2 .+ sqrt.(sigma2) .* randn(nobs);
data = (y = y, x1 = x1, x2 = x2);

Groupwise Heteroskedasticity

The groupwise model assumes a constant variance within each group $g$:

\[\begin{aligned} \sigma_i^2 &= \sigma_g^2, \quad i \in g \end{aligned}\]

We simulate four groups with increasing variance.

groups   = repeat(["A", "B", "C", "D"], inner = nobs ÷ 4);
sigma_gw = [0.5, 1.0, 1.5, 2.0];
sigma_g  = [sigma_gw[findfirst(==( g), ["A","B","C","D"])] for g in groups];
y_gw     = b[1] .+ b[2] .* x1 .+ b[3] .* x2 .+ sigma_g .* randn(nobs);
data_gw  = (y = y_gw, x1 = x1, x2 = x2);

MLE (groupwise_mle): exact MLE standard errors from $(X^\top W X)^{-1}$:

groupwise_mle(@formula(y ~ x1 + x2), data_gw, groups)

AR(1) Estimators

We simulate data with AR(1) errors: $u_t = 0.7\, u_{t-1} + e_t$.

eps  = randn(nobs);
u_ar = zeros(nobs);
for t in 2:nobs; u_ar[t] = 0.7 * u_ar[t-1] + eps[t]; end
y_ar    = b[1] .+ b[2] .* x1 .+ b[3] .* x2 .+ u_ar;
data_ar = (y = y_ar, x1 = x1, x2 = x2);

R Cross-Validation

Each MLE estimator has an exact R counterpart in nlme::gls. Below we run both on the same dataset — generated once in Julia with StableRNG and saved to CSV so R can read it back — so the output tables can be compared directly. The data uses StableRNG(42) for the predictors and StableRNG(99) for the noise.

using StableRNGs
rng_r  = StableRNG(42);
rng_r2 = StableRNG(99);
n_r    = 500;
x1_r   = randn(rng_r, n_r);
x2_r   = randn(rng_r, n_r);
Xr     = hcat(x1_r, x2_r);
br     = [1.0, 2.0, -1.0];

Consistency: Exponential MLE

Combined AR(1) + Heteroskedasticity

The DGP is $u_t = \rho\, u_{t-1} + \sigma_t\, \varepsilon_t$ with Harvey-type heteroskedasticity in the innovations. True parameters: $\rho = 0.7$, $\boldsymbol{\gamma} = [1,\, 0]$ on $(|x_1|, x_2)$ (reusing sigma_exp from the Exponential Variance section above).

Both estimators run the log-variance regression in the original space: the Sequential estimator regresses the log squared Prais-Winsten residuals on $\mathbf{Z}$, since the innovations $\sigma_t \varepsilon_t$ have variance $\sigma_0^2 \exp(\mathbf{z}_t^\top \boldsymbol{\gamma})$; the Joint estimator maximises the exact likelihood. As in the sections above, Z = [|x1|, x2] is passed, so both report $\boldsymbol{\gamma}$ for the variables the variance depends on.

u_hae = zeros(nobs);
for t in 2:nobs; u_hae[t] = 0.7 * u_hae[t-1] + sigma_exp[t] * eps[t]; end
y_hae    = b[1] .+ b[2] .* x1 .+ b[3] .* x2 .+ u_hae;
data_hae = (y = y_hae, x1 = x1, x2 = x2);

Heteroskedasticity Tests

HARE provides two score (LM) tests for heteroskedasticity that are unique to the package. Both test $H_0\colon \gamma = 0$ (homoskedasticity) and are distributed as $\chi^2(p)$ under $H_0$, where $p$ is the number of variance regressors (columns of $Z$ excluding the intercept).

We reuse the exponential-variance dataset from the first section ($n = 500$, $\log\sigma_i^2 = x_{1i}$), so both tests should reject strongly. The R equivalents are skedastic::harvey() and skedastic::glejser().

Harvey test – LM statistic $\text{ESS}/\text{trigamma}(1/2)$ from the auxiliary regression of $\log\hat{u}_i^2$ on $Z$:

y_test   = b[1] .+ b[2] .* x1 .+ b[3] .* x2 .+ sigma_exp .* randn(nobs);
data_test = (y = y_test, x1 = x1, x2 = x2);

harvey_test(@formula(y ~ x1 + x2), data_test)
